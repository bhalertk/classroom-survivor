# 下課生存戰

直接用瀏覽器開啟 [play.html](play.html) 就能玩，不需要安裝套件或連網。若先前已開著遊戲頁面，請關閉舊分頁並重新開啟。

## 玩法

- 主角是轉學生。開場有三頁劇情和可操作的新手教學。
- WASD、方向鍵或手機左下角搖桿移動。鉛筆會自動揮砍附近的方塊人。
- 擊退方塊人可撿經驗光點。升級時從藍莓、手槍、甩炮中選一項；選完道具會掉在附近，走過去撿起來才會成為工具。
- 方塊人會突刺。每次突刺有 1% 機率召喚 100 隻方塊人。
- 撐過兩分鐘即可下課。P 或畫面右上角可暫停。

`index.html`、`style.css`、`story.css`、`game.js` 是原始檔。修改後執行 `node build.js` 可重新產生單檔版 `play.html`。執行 `node verify.js` 可檢查主要遊戲流程。
