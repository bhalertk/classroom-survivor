# Classroom Survivor｜下課生存戰

一款以教室為舞台的瀏覽器生存遊戲。你是轉學第一天的新同學，教室裡的方塊人突然開始攻擊。用鉛筆保護自己、收集經驗取得新工具，撐到下課鐘響。

目前是可玩的遊戲原型，一局約 2 分鐘，支援電腦鍵盤和手機觸控操作。

## 開始遊玩

下載這個專案後，用瀏覽器開啟 **`play.html`**。它是單一檔案，不需要安裝套件或連網。請用瀏覽器開啟檔案，而不是在 GitHub 的原始碼檢視頁中執行。

## 遊戲內容

- **轉學生的故事**：三頁開場劇情，以及可操作的新手教學。
- **鉛筆揮砍**：開局武器會自動攻擊近距離的敵人。
- **方塊人敵人**：會靠近並突刺；每次突刺有 1% 機率召喚 100 隻方塊人。
- **經驗升級**：撿取敵人掉落的經驗光點，升級時從藍莓、手槍、甩炮中三選一。選完後還要撿起地上的工具才會裝備。
- **三種工具**：藍莓砸向敵人、手槍自動單發射擊、甩炮碰到敵人後爆炸並造成範圍傷害。重複選取可以強化工具。
- **生存目標**：撐過兩分鐘，迎接下課鐘聲。

## 操作方式

| 操作 | 電腦 | 手機／平板 |
| --- | --- | --- |
| 移動 | `WASD` 或方向鍵 | 左下角虛擬搖桿 |
| 攻擊 | 自動攻擊 | 自動攻擊 |
| 選擇升級 | 點選卡片或按 `1`、`2`、`3` | 點選卡片 |
| 暫停 | `P`、`Esc` 或右上角按鈕 | 右上角按鈕 |

## 開發與測試

遊戲以 HTML、CSS 和原生 JavaScript 製作，畫面由 Canvas 繪製。`index.html`、`style.css`、`story.css` 和 `game.js` 是原始檔；`play.html` 是方便直接開啟的單檔版本。

修改原始檔後，使用 Node.js 重新產生單檔版本並執行流程測試：

```sh
node build.js
node verify.js
```

`verify.js` 會檢查劇情、教學、升級拾取、甩炮碰撞，以及方塊人召喚規則的主要流程。
